# Reference Data

This directory contains inputs and output for the investigation of Section 9.9.2 in Crisfield Volume 1. 

- `i992.inp`: Input file written by CMP to simulate the problem using the `NFEA` (`nonlin2`) Fortran program provided in Crisfield Volume 2
- `inpt2.dat` Input file provided with the `NONLTD` Fortran program of Volume 1.
